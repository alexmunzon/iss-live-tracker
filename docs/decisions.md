# Decisions

| #   | Date       | Decision                                                                                         | Why                                                                                                                                                                                                                                                                 |
| --- | ---------- | ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D1  | 2026-10-11 | Public project, hosting TBD                                                                      | Owner choice. Build to public standards; deployment is a separate approval.                                                                                                                                                                                         |
| D2  | 2026-10-11 | Session trail in first release (A18 in scope)                                                    | Owner choice. Bounded to 120 points / 10 min, observed only.                                                                                                                                                                                                        |
| D3  | 2026-10-11 | Where the ISS at is the only provider; no automatic fallback                                     | A different calculation source would change the meaning of the data.                                                                                                                                                                                                |
| D4  | 2026-10-11 | Leaflet 1.9.4 from npm, bundled locally                                                          | Stable line; the download page's CDN snippets point at a 2.0 alpha.                                                                                                                                                                                                 |
| D5  | 2026-10-11 | Dependencies pinned to the newest version ≥ 14 days old; `ignore-scripts=true`; `save-exact`     | Supply-chain caution. Correction (security review): `fsevents@2.3.3` (optional, dev, macOS) declares an install script; `ignore-scripts=true` stops it from running. No other package declares one.                                                                 |
| D6  | 2026-10-11 | TypeScript 6.0.3, not 7.0.2                                                                      | typescript-eslint 8.70.1 requires TypeScript < 6.1.0.                                                                                                                                                                                                               |
| D7  | 2026-10-11 | No MSW                                                                                           | Injected `fetch` covers unit tests; Playwright `page.route` covers E2E. One fewer dependency.                                                                                                                                                                       |
| D8  | 2026-10-11 | Assume `Date`, `Retry-After` and `X-Rate-Limit-*` are unreadable in browsers                     | Browser spike: only `cache-control`, `content-length` and `content-type` were readable cross-origin.                                                                                                                                                                |
| D9  | 2026-10-11 | Bounded world map (no world copies)                                                              | Simplest correct antimeridian behavior: the marker jumps and the trail is split.                                                                                                                                                                                    |
| D10 | 2026-10-11 | Implementation subagents run on claude-opus-5-5                                                  | The project prompt requires it for implementation and review agents (overrides the Sonnet default for this project). Mechanical sweeps may still use Sonnet.                                                                                                        |
| D11 | 2026-10-11 | The chosen host must support custom response headers                                             | `frame-ancestors` and a reliable CSP only work as response headers, not `<meta>`. Header set: `securityHeaders` in vite.config.ts.                                                                                                                                  |
| D12 | 2026-10-11 | API fetch uses `referrerPolicy: 'no-referrer'`; the page keeps `strict-origin-when-cross-origin` | The ISS API doesn't need our origin; the OSM policy requires a Referer for tiles.                                                                                                                                                                                   |
| D13 | 2026-10-11 | Server-requested waits capped at 1 h; clock-skew streak handling                                 | Security review H1/H2: prevents permanent stalls, timer overflow loops and a frozen marker.                                                                                                                                                                         |
| D14 | 2026-10-11 | Production CSP has no `unsafe-inline`                                                            | Leaflet sets positions through CSSOM, which CSP allows. The production build has no inline script or style (verified in dist/index.html at G2).                                                                                                                     |
| D15 | 2026-10-11 | Visitors whose clock is > 30 s slow see a clock warning, not a position                          | Strict reading of the future-timestamp rule. Rare on network-synced devices. Listed as a known limitation.                                                                                                                                                          |
| D16 | 2026-10-11 | Samples up to 2 s ahead of the local clock count as on time (`futureSkewToleranceMs`)            | Live finding: real, current samples often arrive about 1 s "in the future" because the provider timestamp has 1 s resolution and clocks drift. Without the tolerance, healthy data was labelled Delayed with a clock warning. The 30 s rejection rule is unchanged. |
| D17 | 2026-10-11 | Owner lifted the 3-concurrent-writer cap                                                         | Owner request, to speed up release prep. File ownership still applies: one writer per file, each writer in its own worktree or file set, so parallel edits cannot overwrite each other.                                                                             |
